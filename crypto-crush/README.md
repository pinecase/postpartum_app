# 🪙 币圈消消乐 · Crypto Crush

一个专为币圈人打造的消消乐(Match-3)小游戏。单文件、零依赖,浏览器打开 `index.html` 即玩,手机/桌面均可(支持触摸滑动)。

## 游戏模式

| 模式 | 规则 |
|------|------|
| ⛽ 经典模式 | 30 步 Gas,每 5 步刷一条利空新闻(FUD 方块),每 8 步一条利好(空投特殊方块) |
| 🐻 熊市生存 | 90 秒限时,步数不限;FUD 每 6 秒刷一个;单回合消除 ≥10 块回血 +2s、≥18 块 +5s |

## 币圈特色消除

| 触发方式 | 特殊方块 | 效果 |
|----------|----------|------|
| 竖排 4 连 | 🚀 火箭 | To the Moon!打穿整列 |
| 横排 4 连 | 📈 神级拉盘 | 一根大阳线扫平整行 |
| L / T 形交叉 | 💥 爆仓弹 | 炸掉 3×3 区域 |
| 5 连 | 🐋 巨鲸 | 与任意币交换 → 吸干全场该币种 |
| 🐋 + 🐋 | 双鲸对撞 | 大牛市,清空全场! |

- **双击**特殊方块可直接引爆;两个特殊方块**互换**会同时触发
- 连锁反应叠加**杠杆倍数**(2x、3x……),分数翻倍
- 无路可走时市场自动**重新洗牌**

## 😱 FUD 障碍方块

利空新闻会把普通币变成 FUD 方块:**不能移动、不能交换、不参与消除**,还占着位置。清除方式:

- 在它**四周相邻**的位置完成消除(波及澄清)
- 用 🚀 / 📈 / 💥 等特殊方块的爆炸范围直接轰掉

澄清一块 FUD 奖励 30 × 杠杆 的市值。
