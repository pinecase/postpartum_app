# 🪙 币圈消消乐 · Crypto Crush

一个专为币圈人打造的消消乐(Match-3)小游戏。单文件、零依赖,浏览器打开 `index.html` 即玩,手机/桌面均可(支持触摸滑动)。

## 玩法

交换相邻的币种方块,3 个及以上同币种连成一线即可消除。每次交换消耗 1 点 ⛽ Gas(共 30 点),Gas 耗尽即强制清算,结算你的总市值 💰。

## 币种

| 方块 | 币种 |
|------|------|
| ₿ | BTC |
| Ξ | ETH |
| Ð | DOGE |
| ◎ | SOL |
| ₮ | USDT |
| 🐸 | PEPE |

## 币圈特色消除

| 触发方式 | 特殊方块 | 效果 |
|----------|----------|------|
| 竖排 4 连 | 🚀 火箭 | To the Moon!打穿整列 |
| 横排 4 连 | 📈 神级拉盘 | 一根大阳线扫平整行 |
| L / T 形交叉 | 💥 爆仓弹 | 炸掉 3×3 区域 |
| 5 连 | 🐋 巨鲸 | 与任意币交换 → 吸干全场该币种 |
| 🐋 + 🐋 | 双鲸对撞 | 大牛市,清空全场! |

- **双击**特殊方块可直接引爆
- 两个特殊方块**互换**会同时触发
- 连锁反应会叠加**杠杆倍数**(2x、3x……),分数翻倍
- 每 8 步触发一条**📰 利好新闻**,随机空投一个特殊方块
- 无路可走时市场自动**重新洗牌**

## 计分

- 普通方块:10 × 当前杠杆
- 特殊方块:60 × 当前杠杆
- 历史最高分存在浏览器 localStorage 里
