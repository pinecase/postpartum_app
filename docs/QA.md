# QA 手册

## 自动化测试（每次改动必跑）

| 命令 | 内容 | 门禁 |
|------|------|------|
| `npm test` | 48+ 个单元/API 测试（Vitest） | CI 必须全绿才部署 |
| `npm run test:coverage` | 覆盖率 + 阈值检查 | alerts≥85%、app≥70% 行覆盖 |
| `npm run test:bdd` | 8 个 Gherkin 中文验收场景（Cucumber） | CI 必须全绿才部署 |
| `npm run test:mutation` | 变异测试（Stryker） | 变异分低于 60 即失败 |
| `npm run build`（client 内含 tsc） | TypeScript 严格类型检查 | 编译失败即失败 |

CI（GitHub Actions）在每次推送时自动执行以上前三项，**测试不通过不会部署**。

## 测试分层

- **单元测试** `tests/unit/`：时间格式化、CSV 转义、三语字典完整性（键/占位符一致）、
  任务→记录同步规则（13 个场景）、预警规则（真实 SQLite 上验证阈值）
- **API 测试** `tests/api/`：入住、记录 CRUD（含照片级联删除）、任务（内部备注/编辑/完成）、
  日报关联、管理汇总、PIN 门禁
- **验收测试（Gherkin）** `tests/bdd/features/`：业务语言书写，覆盖入住→记录→预警→修正→离所
  全流程与访问码保护
- **UI 冒烟**：发布后按下方手动清单过一遍关键路径

## 发布前手动冒烟清单（5 分钟）

设备矩阵：iPhone Safari + 安卓 Chrome + 电脑 Chrome 各过一遍主路径。

1. [ ] 打开网站 → 左上角版本号与本次发布一致（无痕窗口验证）
2. [ ] PIN 锁屏出现 → 输入访问码进入
3. [ ] 工作台：英雄卡数字合理、喂养计时环颜色正确
4. [ ] 新建任务「喂奶时间」→ 选母乳亲喂 → 左右奶/姿势/计时器出现 → 保存
5. [ ] 进入该宝宝页 → 喂养标签有这条记录 → ✎ 编辑改奶量 → 生效
6. [ ] 拍照（相机 + 相册各一张）→ 记录上 📷 可查看
7. [ ] 语音输入说一句 → 文字进入说明
8. [ ] 日报 → 自动汇总本班 → 复制 → 提交
9. [ ] 管理后台：表格/图表渲染、导出 CSV 打开无乱码
10. [ ] 切换 English → 界面翻译正常

## 数据安全例行

- 每周从管理后台导出一次全量 CSV 留档
- 访问码每季度更换；员工离职立即更换
- 照片含婴儿影像，勿将网址外传
